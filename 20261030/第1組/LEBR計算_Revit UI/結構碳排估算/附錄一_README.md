# 附錄一 P-LCC 初級資材碳排資料（CSV）

來源：內政部建築研究所《2025 低碳（低蘊含碳）建築評估手冊》附錄一「ABRI 初級資材碳排資料庫（P-LCC, 2022）」，手冊第 52～55 頁（PDF 第 64～67 頁）。

檔案：`附錄一_P-LCC_2022.csv`，共 120 筆材料，一列一種材料。編碼為 UTF-8（含 BOM），可直接用 Excel、Python（`encoding="utf-8-sig"`）或交給 AI 讀。

> **狀態：草稿。** 數字由程式從 PDF 抽出，並用兩種方法交叉驗算（數字之間的加總關係、PDF 純文字比對）。目前尚未完成逐筆人工核對，正式使用前請對照手冊原頁。

## 這份表在算什麼

每一列是「一單位材料」從原料開採到運到工地（A1～A4 階段）的碳排放量，單位是 **kgCO2e／每單位**。

例如「鋼筋及鐵件」單位是 kg、總碳排 1.15：每用 1 kg 鋼筋，碳排 1.15 kgCO2e。

**用法：材料數量 × `total_a1_a4` = 碳排（kgCO2e）。** 數量的單位要和 `unit` 欄相同，例如混凝土是 m3、鋼筋是 kg。

## 欄位說明

| 欄位 | 意思 | 範例 |
|---|---|---|
| `id` | 材料編號，本資料庫自訂（手冊沒有編號），依手冊順序排列 | `PLCC-040` |
| `category` | 手冊的分類：金屬、砂石、水泥、玻璃、木材、木質板材、化學塑膠 | `水泥` |
| `name` | 材料／工項名稱，照手冊原文 | `預拌混凝土（2000psi）` |
| `unit` | 計量單位：`kg`、`t`（公噸）、`m2`、`m3`、`塊`、`片` | `m3` |
| `a1` | A1 原料開採（kgCO2e／單位） | `5.13` |
| `a2` | A2 原料運輸 | `19.24` |
| `a3` | A3 產品生產 | `214.84` |
| `a4` | A4 成品運輸 | `4.57` |
| `combined_stages` | 手冊把幾個階段**合併成一格**時，合併的範圍；沒合併就空白 | `A1-A3` |
| `combined_value` | 合併那一格的數值（被合併的 `a1`～`a4` 會留空） | `2.26` |
| `total_a1_a4` | **總碳排（A1～A4），計算時用這欄** | `243.78` |
| `stage_detail` | `separate`：四階段分開列；`combined`：有合併格；`total_only`：手冊只給總量 | `separate` |
| `manual_issue` | 手冊本身數字前後不一致的說明（不是抽取錯誤） | 見下方 |
| `note` | 手冊表內的附註，以及木材類的註腳 | |
| `book_page` | 手冊印刷頁碼 | `53` |
| `pdf_page` | PDF 檔的頁碼（= 印刷頁碼 + 12） | `65` |

### 空白和 0 不一樣

- **空白**：手冊那一格沒有數字，或已併入 `combined_value`。
- **`0`**：手冊明確印 0（例如紅磚的 A2）。

### 合併儲存格怎麼讀

手冊有些材料只給幾個階段的合計。例如「鋼胚（高爐）」：

| a1 | a2 | a3 | a4 | combined_stages | combined_value | total_a1_a4 |
|---|---|---|---|---|---|---|
| | | | 0.011 | A1-A3 | 2.26 | 2.27 |

意思是 A1～A3 合計 2.26，A4 是 0.011，總共 2.27。

**只需要總量時，直接用 `total_a1_a4`，不用管這兩欄。**

## 手冊本身的問題（已對照原頁確認）

有 3 筆的分階段數字加起來不等於總量，記在 `manual_issue` 欄：

| 編號 | 材料 | 問題 | 可能原因 |
|---|---|---|---|
| PLCC-013 | 門窗鋁框（m2） | 14.4 + 0.0055 = 14.4055，總量印 14.38 | 四捨五入或筆誤 |
| PLCC-056 | 石膏（kg） | 0.035 + 0.0038 = 0.0388，總量印 0.35 | 總量可能少一個 0（應為 0.035～0.039） |
| PLCC-115 | PE 防水布（kg） | 0.252 + 0 = 0.252，總量印 0.042 | 兩者差 6 倍，原因不明 |

這 3 筆在 CSV 裡**保留手冊印的值**，沒有自行修正。使用前請團隊決定採哪個值，或以官方勘誤為準。

## 其他注意

- **木材、木質板材**：手冊註腳說明，木材的固碳量（樹木生長時吸收的碳）不在本資料庫範疇；數據引用本土木質廠的平均值。
- **同名不同單位**：有些材料有兩列，例如「門窗鋁框」有 kg 和 m2 兩種、「輕質水泥」有 m3 和 kg 兩種。計算時要選和數量單位相同的那一列。
- **名稱裡的規格**：混凝土強度（psi）、板厚（mm）、尺寸（cm）都寫在 `name` 裡，需要時請自行拆欄。
- 本表只涵蓋 A1～A4（製造與運輸到工地），**不含**施工、使用、維修與拆除階段，那些在手冊第四章另有公式。

## 給 AI 的使用提示

把 CSV 和這份 README 一起交給 AI，並告訴它：

1. 計算碳排用 `total_a1_a4` × 數量，數量單位必須和 `unit` 相同。
2. `combined_stages` 不為空時，`combined_value` 是那幾個階段的合計，不是 A1 的值。
3. `manual_issue` 不為空的 3 筆，數字有疑義，引用時要特別說明。
