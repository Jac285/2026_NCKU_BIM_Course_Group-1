## 六、需要先決定的問題

1. **程式語言與位置**：若是 C#，建議放在 `csharp/`（不依賴 Revit API，C# 7.3）；若是其他語言，需先決定整合方式（移植或以 JSON 交換）。
2. **輸出形式**：估算結果是「設計案 C 值」，還是「Sp、F、S 等參數」？影響引擎如何接收。
3. **回傳表單的方式**：
   - (a) 估算視窗回傳結果給表單，表單暫存於記憶體（不儲存）；
   - (b) 估算結果寫入新的專案參數（需要新增參數，並更新「建立參數」與文件）；
   - (c) 估算視窗直接寫入專案資訊。
4. **估算是否需要 Revit**：若需要讀取模型（例如幾何），應放在 `revit-addin/Revit/`；若只需數值輸入，則放在 `csharp/`。
5. **是否影響基準案**：目前規定不影響，請再次確認。
