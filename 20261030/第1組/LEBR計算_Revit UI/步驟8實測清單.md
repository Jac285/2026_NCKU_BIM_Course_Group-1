# 步驟 8：Revit 2027 實測清單

適用版本：本分支工作目錄中的 LEBR 外掛（已於步驟 7 安裝到 `Addins\2027\LebrCarbon`）。

## 一、開始前

- [ ] 確認 Revit 2027 已完全關閉（工作管理員沒有 Revit 程序）。
- [ ] 測試模型使用副本：`C:\Users\Jason\dev\lebr_step8_test\NCKU_9hours_intro_course_step8.rvt`。**不要直接開啟或覆蓋原檔**，也不要把 `.rvt` 放進 repo。
- [ ] 確認 `Addins\2027\LebrCarbon.addin` 指向 `LebrCarbon\LebrCarbon.dll`。

## 二、載入外掛

- [ ] 開啟 Revit 2027，開啟副本 `NCKU_9hours_intro_course_step8.rvt`。
- [ ] 若出現「無法驗證此增益集的發佈者」，選擇「永遠載入」。
- [ ] 功能區出現 **LEBR** 頁籤，內含「建立參數」、「專案設定」、「開始計算」三個按鈕。

## 三、建立參數（新版增加 2 個參數）

- [ ] 按「建立參數」，完成後應顯示已建立參數（新版應新增 `LEBR_LL_Durable`、`LEBR_LL_Quality`）。
- [ ] 專案資訊（管理 → 專案資訊）中可看到 `LEBR_LL_Durable`、`LEBR_LL_Quality`。
- [ ] 再按一次「建立參數」，不應產生重複參數。

## 四、專案設定：開啟與預設值

- [ ] 按「專案設定」，表單開啟，標題顯示專案名稱。
- [ ] 預設值：Rs = 0.95；CSER 未勾選、值 0.00；覆寫欄位全部收合；LL 下拉為「無」。
- [ ] 構造為 RC 時，CSER 可勾選，LL 項目 1、2 可選。
- [ ] 「使用估算」勾選後，A 區所有欄位鎖定；取消後恢復。

## 五、構造條件

| 測試 | 操作 | 預期 |
|---|---|---|
| 5-1 | 構造選 RC | CSER 可勾選；LL 項目 1、2 可選 |
| 5-2 | 構造選 SRC | CSER 可勾選；LL 項目 1、2 **不可選** |
| 5-3 | 構造選 S | CSER 灰色不可勾選，值為 0.00；LL 項目 1、2 不可選 |
| 5-4 | 構造選 wood | 同 S |
| 5-5 | 先在 RC 選 LL 項目 1，再改為 SRC | 項目 1 被清除，回到「無」 |

## 六、CSER

| 測試 | 操作 | 預期 |
|---|---|---|
| 6-1 | RC，未勾選 CSER | 儲存後 `LEBR_CSER` = 0 |
| 6-2 | RC，勾選 CSER，輸入 1.7 | 儲存後 `LEBR_CSER` = 1.7 |
| 6-3 | RC，勾選 CSER，輸入 0 | 儲存後 `LEBR_CSER` = 0 |

## 七、LL（優惠係數）

| 測試 | 操作 | 預期 `LEBR_LL` | 預期 `LEBR_LL_Durable` / `_Quality` |
|---|---|---|---|
| 7-1 | RC，只選項目 2（0.02），附證明 | 0.02 | 2 / 0 |
| 7-2 | RC，項目 1（0.04）+ 項目 3（0.05），附證明 | 0.08（限制上限） | 1 / 3 |
| 7-3 | SRC，項目 1 + 項目 3，附證明 | 0.05（項目 1 不計） | 清除 / 3 |
| 7-4 | RC，項目 1 + 項目 3，**未附證明** | 0 | 1 / 3 |
| 7-5 | 只選項目 4（0.04），附證明 | 0.04 | 0 / 4 |

- [ ] 表單的「合計 LL」與「寫入 LEBR_LL」文字與上表一致。

## 八、覆寫欄位

- [ ] 未勾選覆寫時，覆寫欄位隱藏。
- [ ] 勾選 A-2 覆寫，填入 S = 14、Sp = 1.2、F = 1.1；取消勾選後欄位清空，儲存後 `LEBR_S`、`LEBR_Sp`、`LEBR_F` = 0。
- [ ] 勾選 B 區 AFu 覆寫，填入 1000；取消後清空，儲存後 `LEBR_AFu` = 0。

## 九、儲存與還原

- [ ] 依測試 7-2 設定後儲存，關閉表單，再開「專案設定」：
  - 耐久設計顯示項目 1，高品質施工顯示項目 3。
  - 證明文件勾選，合計 LL 顯示 0.08。
  - CSER、Rs、構造等欄位與儲存前一致。
- [ ] 按「讀取目前專案值」，表單還原為專案資訊中的值。

## 十、必填檢查與計算

- [ ] I、SaD、Fu、L、D0 留空時，表單顯示缺少的必填項目。
- [ ] 設計案缺少 Sp 或 F（不填覆寫，且模型無法算出時）：開始計算的提醒應顯示「設計案主結構未計算」，基準案仍有計算。
- [ ] 按「開始計算」，計算前檢查正常開啟；結果視窗正常顯示，沒有例外。
