# 專案表單開發

分支：`feat/lebr-plugin-dev`
位置：`20261030/第1組/LEBR碳排外掛/lebr-db/`（程式）、`20261030/第1組/LEBR計算_Revit UI/`（文件）
狀態日期：2026-10-26

## 一、目標

在 Revit 中新增「專案設定」表單，取代手動到專案資訊填寫 `LEBR_*` 參數，並依手冊區分：

- **A 主結構**（基準案同設計案）：A-1 共用項目、A-2 僅設計案項目。
- **B 非主結構**：覆寫 AFu。
- **C 優惠係數（LL）**：表 5-2 兩組下拉選單。

## 二、已確認的決策

| 項目 | 決定 |
|---|---|
| 儲存位置 | 寫回專案資訊的 `LEBR_*` 參數，與手動填寫位置相同 |
| LL 寫入值 | `LEBR_LL` 寫入已限制上限（最多 0.08）的合計值 |
| LL 項目記錄 | 新增 `LEBR_LL_Durable`、`LEBR_LL_Quality` 記錄所選項目編號（0 表示無），用於還原選單 |
| CSER | 未勾選寫入 0；勾選後寫入輸入的數值（可任意數值） |
| CSER 條件 | 構造為 RC 或 SRC 才可勾選 |
| LL 條件 | 項目 1、2 僅構造為 RC 可選（SRC 不可選）；項目 3、4 不限構造 |
| Rs | 下拉 0.95 / 1.00，預設 0.95 |
| 估算選項 | 本次只做 UI 鎖定，不接另外的估算程式，不儲存 |
| 覆寫欄位 | S 同步套用基準案；Sp、F 僅設計案；AFu 設計案與基準案相同；取消勾選即清空 |
| 引擎修改 | 「Sp、F 檢查只用於設計案」與「基準案 EBF = 0」放在獨立 commit，與表單 UI 分開 |
| 參數不存在 | 按「專案設定」時自動建立缺少的參數（不需先按「建立參數」） |
